# 光明教务 · 少儿编程机构教务管理系统

> 一句话：把「学生 → 课包 → 排课 → 点名消课 → 续费预警」整条流水线搬上云端，电脑手机同步，外加一个"说一句话就办好事"的智能助手。

为少儿编程/机器人机构量身打造：课时按**小时**计、课包分**正式+赠送双池**、支持**负课时**、文字一句话排课、Excel 集训表直接导入、点名默认全员到课只标例外——每一个设计都来自机构老板的真实运营习惯。

---

## ✨ 功能总览

### 电脑端
| 模块 | 能做什么 |
|---|---|
| 今日课表 | 今天谁要来、上什么课一屏看清；下课后自动弹出待点名提醒 |
| 学生管理 | 档案（中英文名/年级/家长联系方式）、累计缴费、上课履历 |
| 课包 | 一次缴费录入「正式 100 + 赠送 20」双池，自动算单价；负课时红色显示 |
| 排课 | **文字一句话** / **Excel 表格识别**（合并单元格、总课时核对）/ 手动表单；周课表 + 月课表（今天/本周高亮）；冲突自动检测并标红 |
| 点名消课 | 默认全员到课只标例外；临时加人；逐人换扣哪个课包；撤销自动回冲 |
| 上课记录 | 按学生/月份/课包池筛选，导出 CSV |
| 统计看板 | 月度耗课金额（=确认收入）、赠送池消耗、**待续费名单**（欠最多排最前，一键复制发家长） |

### 手机端（同一套系统，自适应 + 可添加到主屏幕）
打开即今日课程 → 下课自动弹待点名卡片 → 勾选保存即消课。

### 🤖 智能助手（可选接入大模型）
主页输入一句话，先给确认卡片再执行，不会乱动数据：

```
新报了学生小琳，G5，vexiq，36100元，100课时+20赠送比赛课时，加入周三17:20-19:20的班级
周三的 vexiq 班，加入了陈大明 Eason 和刘小华 Alina，以后长期一起上课
10.29的课程全员到齐，全部点名签到
孙昊然明天请假
小琳还剩多少课时
谁该续费了
```

- 未接入大模型时用**内置规则引擎**（离线、零成本），覆盖常见句式
- 接入大模型（DeepSeek/硅基流动/百炼）后**任意说法都能懂**；大模型只负责"听懂"，实体对号与执行全在本地代码，听错一眼可见
- 没听懂的句子自动收集，攒着一次性反馈

## 🧠 核心业务规则

- **课时 = 小时**：单节课默认 2 小时（可设 4），到课扣对应小时数
- **课包双池**：正式池扣费计金额；赠送池（比赛课时）消课计 ¥0，不污染收入统计
- **比赛课自动识别**：排课名字命中「城市赛/华南赛/国赛/世锦赛/锦标赛…」→ 自动改扣赠送池
- **允许负课时**：课时不足照常上课，红色置顶进待续费名单，续费后自动转正
- **续费预警**：正式池剩余 < 20 课时（可配置）自动进名单
- **可撤销**：点名错了随时撤销，课时金额按快照自动回冲

## ☁️ 部署上线

数据：[Supabase](https://supabase.com) 免费版（PostgreSQL）；托管：**GitHub Pages**（公开仓库 + GitHub Actions 自动部署，免费）。
push 到 main 即自动构建发布；生产构建会读取 `.env.production` 中固化的云端配置，打开直达登录页。

> 2026-11-15 定稿：EdgeOne 免费体验到期停服后切换 GitHub Pages。首次启用：仓库 Settings → Pages → Source 选 **GitHub Actions**，之后 push 自动部署（工作流见 `.github/workflows/deploy.yml`）。
> github.io 实测内地可不开 VPN 直连，电脑手机同一网址自适应。

完整步骤见 **[部署指南.md](./部署指南.md)**。
